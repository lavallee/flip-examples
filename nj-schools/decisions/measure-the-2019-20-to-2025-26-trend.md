**Question.** Which file eras can the trend claims rest on?

**Decision.** Measure the 2019-20 to 2025-26 trend on Era-C workbooks only (modern State/District/School xlsx)

**Why.** Pre-2019 files use two older container formats with shifted race/ethnicity categories and header drift (per A6); mixing eras risks reading definitional changes as demographic swings. Era C is format-stable across all four captured years.
