# The naive baseline — declared before anything resolves

Stated now because after the first resolution it's worth nothing:

1. **Enrollment continues its recent drift**: next year ≈ this year
   − 0.8% (the observed 2023-24 → 2025-26 annualized rate in
   nj-schools). Naive 2026-27 estimate: ≈ 1,346,600.
2. **The state publishes on schedule**: a new fall-enrollment ZIP has
   appeared at the DOE index every year for 28 years, typically by late
   winter.
3. **Published files don't get fixed**: the state revises silently when
   it revises at all; cosmetic defects (like the 2025-26 file's stale
   intro sheet) persist.

Every forecast below should beat, or honestly match, these three.
